# Admin Panel User Guide

## 🚀 How to Access the Admin Panel

### Method 1: Footer Link (Recommended)
1. Scroll to the bottom of any page on the website
2. Look for the **"Admin"** link in the footer (bottom right area)
3. Click on it to open the admin login page

### Method 2: Direct URL
1. Add `#/admin` to the end of your website URL
2. Example: `https://yourwebsite.com/#/admin`
3. Press Enter to navigate to the admin login page

## 📋 Admin Dashboard Overview

Once logged in, you'll see the admin dashboard with three main sections in the left sidebar:

### 1. **Pages** - Manage Website Pages
- View all existing pages
- Add new pages
- Edit page content
- Delete pages
- Show/hide pages from navigation

### 2. **Theme** - Customize Appearance
- Change colors (primary, background, text)
- Select fonts
- Choose header style
- Set button styles
- Live preview of changes

### 3. **Site Settings** - Global Configuration
- Update site name
- Edit announcement bar text
- Modify footer text
- Add social media links
- Reset all content to defaults

## 📝 How to Edit Pages

### Step-by-Step Guide:

1. **Navigate to Pages**
   - Click "Pages" in the left sidebar
   - You'll see a list of all website pages

2. **Edit an Existing Page**
   - Click the **"Edit"** button next to any page
   - Or click the page name in the "Quick Edit Pages" section

3. **Modify Page Settings**
   - **Page Title:** Change the page name
   - **URL Slug:** Change the page URL (e.g., "about-us")

4. **Edit Hero Section** (if available)
   - **Hero Image URL:** Paste an image URL
   - **Title:** Main heading text
   - **Subtitle:** Supporting text
   - **Button Text:** Call-to-action button text

5. **Manage Content Sections**
   - Click **"Edit"** on any section to modify it
   - Click **"Delete"** to remove a section
   - Use the **"Add Section"** buttons to add new content:
     - **Text:** Add titles, paragraphs, and buttons
     - **Image:** Display images
     - **Product Grid:** Show products
     - **Newsletter:** Add newsletter signup
     - **Featured:** Display featured collections
     - **Custom:** Add custom HTML content

6. **Save Changes**
   - All changes are saved automatically
   - Refresh the website to see updates

## 🎨 How to Customize the Theme

1. Click **"Theme"** in the left sidebar
2. **Colors:**
   - Use color pickers or enter hex codes
   - Primary Color: Main brand color
   - Background Color: Page background
   - Text Color: Default text color
3. **Typography:**
   - Choose from dropdown (Inter, Cormorant Garamond, etc.)
4. **Style Options:**
   - Header Style: Light or Dark
   - Button Style: Square or Rounded
5. **Preview:**
   - Scroll down to see a live preview
   - Changes apply immediately

---

## ⚙️ How to Configure Site Settings

1. Click **"Site Settings"** in the left sidebar
2. **General Settings:**
   - **Site Name:** Your brand name (appears in header/footer)
   - **Announcement Bar:** Top banner message
   - **Footer Text:** Copyright and footer information
3. **Social Media Links:**
   - Paste full URLs for Instagram, Twitter, YouTube, Telegram
   - Example: `https://instagram.com/yourbrand`
4. **Reset:**
   - Click "Reset All Content" to restore defaults
   - ⚠️ This cannot be undone!

## 💡 Tips for Non-Technical Users

### Adding Images
- Use image URLs from:
  - Your own website
  - Image hosting services (Imgur, Cloudinary, etc.)
  - Direct links to images
- Recommended size: At least 1200px wide for best quality

### Writing Content
- Keep text concise and clear
- Use proper grammar and punctuation
- Break long text into multiple paragraphs
- Use headings to organize content

### Testing Changes
- Always preview your changes on the live site
- Check on both desktop and mobile views
- Test all links and buttons
- Verify images load correctly

### Best Practices
1. **Make small changes** - Edit one section at a time
2. **Test frequently** - Check the live site after each change
3. **Backup content** - Copy important text before major edits
4. **Use quality images** - High-resolution, properly sized images
5. **Keep it simple** - Don't overcrowd pages with too many sections

## 🔍 Troubleshooting

### "Admin button doesn't work"
- Make sure you're clicking the "Admin" link in the footer
- Try adding `#/admin` to your URL manually
- Clear your browser cache (Ctrl+Shift+R or Cmd+Shift+R)

### "Changes not showing on website"
- Refresh the page (F5 or Ctrl+R)
- Clear browser cache (Ctrl+Shift+R)
- Check if the page is marked as "Visible" in Pages settings

### "Images not loading"
- Verify the image URL is correct
- Ensure the image is publicly accessible
- Try a different image hosting service
- Check that the URL starts with `https://`

### "Can't log in"
- Double-check username and password
- Username: `admin`
- Password: `admin123`
- Make sure there are no extra spaces

### "Theme changes not applying"
- Refresh the page
- Check browser console for errors (F12 → Console)
- Try resetting theme to defaults
