# Admin Panel Guide

## Accessing the Admin Panel

1. **Navigate to Admin**: Click the "Admin" link in the footer of the website, or go to `#/admin` in the URL
2. **Login Credentials**:
   - Username: `admin`
   - Password: `admin123`

## Admin Dashboard Features

### 1. Pages Management
- **View all pages**: See a list of all website pages
- **Add new pages**: Create custom pages with unique content
- **Edit pages**: Modify page title, URL slug, and content sections
- **Delete pages**: Remove pages you no longer need
- **Toggle visibility**: Show/hide pages from the navigation menu

### 2. Page Editor
When editing a page, you can:
- **Change page settings**: Update title and URL slug
- **Edit hero section**: Modify hero image, title, subtitle, and button text
- **Manage sections**: Add, edit, reorder, or delete content sections
- **Section types available**:
  - Text: Add titles, paragraphs, and buttons
  - Image: Display images with alt text
  - Product Grid: Show products (all or new arrivals only)
  - Newsletter: Newsletter signup form
  - Featured: Featured collections display
  - Custom: Custom HTML content

### 3. Theme Customization
Customize your website's appearance:
- **Colors**: Primary color, background color, text color
- **Typography**: Choose from multiple font families
- **Header style**: Light or dark header
- **Button style**: Square or rounded buttons
- **Live preview**: See changes in real-time

### 4. Site Settings
Configure global site settings:
- **Site name**: Change the brand name displayed in header and footer
- **Announcement bar**: Update the top announcement message
- **Footer text**: Modify copyright and footer information
- **Social media links**: Update Instagram, Twitter, YouTube, and Telegram URLs
- **Reset all content**: Restore default settings (use with caution)

## Tips for Non-Technical Users

### Adding Content
1. Go to Pages → Select a page → Click "Edit"
2. Use the "Add Section" buttons to add new content blocks
3. Click "Edit" on any section to modify its content
4. Changes are saved automatically

### Editing Text
- Simply click into text fields and type your new content
- For longer text, use the textarea fields
- HTML is supported in custom sections

### Changing Images
- Paste image URLs directly into image fields
- You can use images from:
  - Your own hosting
  - Image hosting services (Imgur, Cloudinary, etc.)
  - Direct links to images

### Theme Changes
1. Go to Theme in the sidebar
2. Use color pickers or enter hex codes
3. Preview changes at the bottom of the page
4. Changes apply immediately across the site

### Managing Navigation
- Pages marked as "Visible" appear in the navigation menu
- Uncheck "Visible" to hide a page from navigation
- The page will still be accessible via direct URL

## Best Practices

1. **Save frequently**: While changes auto-save, refresh the page to ensure everything is saved
2. **Preview changes**: Always check the live site after making major changes
3. **Test on mobile**: Check how your changes look on different screen sizes
4. **Backup content**: Copy important text content before making major changes
5. **Use quality images**: High-resolution images (at least 1200px wide) for best results

## Troubleshooting

### Changes not showing?
- Refresh the page
- Clear browser cache (Ctrl+Shift+R or Cmd+Shift+R)
- Check if the page is marked as visible

### Images not loading?
- Verify the image URL is correct and accessible
- Ensure the image is publicly accessible (not behind a login)
- Try using a different image hosting service

### Theme not applying?
- Refresh the page to see theme changes
- Check browser console for errors (F12)

## Support

For technical issues or questions:
- Check the browser console for error messages (F12 → Console tab)
- Try resetting to default settings if issues persist
- Contact technical support with specific error messages
